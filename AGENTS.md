# Работа агентов в ai-mechanic

- Перед изменениями по задаче или эксперименту применяй `$project-context`. Если клиент не обнаруживает skills, прочитай `.agents/skills/project-context/SKILL.md` и выполни `start` из корня checkout. Уточни связанную GitHub Issue по выводу команды.
- Сверяй требования, владельцев компонентов и архитектурные контракты с [общим контекстом проекта](docs/shared-project-context.md).
- После задачи синхронизируй проверенный результат со связанной Issue. Для эксперимента добавь комментарий в общий [журнал](https://github.com/ofdun/ai-mechanic/issues/9) и свяжи его с задачей. Команды приведены в skill.
- Архитектура, задачи, ответственные, решения, блокеры, контракты и результаты экспериментов ведутся в GitHub Issues. Публичный репозиторий принимает только согласованные к публикации сведения.
- Работай в своей ветке, сохраняя изменения коллег. Акустическую классификацию выполняет внешний ML API. Компоненты ML/RAG/Agent и веб-интерфейс интегрируются по согласованному контракту.
