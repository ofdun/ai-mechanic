# Работа агентов в ai-mechanic

- Перед изменениями по задаче или эксперименту применяй `$project-context`. Если клиент не обнаруживает skills, прочитай `.agents/skills/project-context/SKILL.md` и выполни `start` из корня checkout. Уточни связанную GitHub Issue по выводу команды.
- После задачи синхронизируй проверенный результат со связанной Issue. Для эксперимента сначала запиши прогон в Google Sheets, затем укажи его ID в Issue. Команды и правила приведены в skill.
- Архитектура, задачи, ответственные, решения, блокеры и согласование контрактов ведутся в GitHub Issues. Измерения хранятся в общей Google Sheets. Публичный репозиторий принимает только согласованные к публикации сведения.
- Работай в своей ветке, сохраняя изменения коллег. Акустическую классификацию выполняет внешний ML API. Компоненты ML/RAG/Agent и веб-интерфейс интегрируются по согласованному контракту.
